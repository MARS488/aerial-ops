# Hosting

No host was purchased. No deployment was started. No domain was registered.

## Use this

Run the package on the Linux computer you already have, with the commands in `README.md`. The process binds `127.0.0.1` and uses the Python standard library plus a SQLite file on that disk.

That uses the CPU, memory, and disk of a machine you already run. This package did not create a new account or a metered API bill. The cloud VM run also used existing agent compute; it is not a server the parent has to keep, and it is not reachable from that Linux computer.

Measured on the passing cloud VM run: one Python process, one SQLite file with 1 job row, 2 history events, and 1 score event. No additional package was installed.

## Do not start from this note

A hosted prototype was discussed and is not authorized.

The figure supplied with the request, and not re-quoted or purchased here, was Render's Hobby prototype at 512 MB memory and 1 GB disk, about $7.25 per month baseline plus usage and tax. Starting that service would be a new signup and a charge. Do not sign up unless a later approval names that exact price and the reason.

Base44 was declined. This package does not download it or call it.

GitHub Pages is the live site path for a different branch. This sandbox is not part of that site and was not published there.
